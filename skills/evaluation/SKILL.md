# 技能 7：自动评测

## 输入
报告 `.md` + `reports/{code}_facts.json` + `reports/{code}_annual_report_qa.json`

## 输出
`reports/{code}_eval_{报告名}.json`

## 运行
```
python skills/evaluation/evaluate.py                                    # 评测 draft.md
python skills/evaluation/evaluate.py reports/sz000538_draft_v1.md reports/sz000538_final.md
```

## 检查项
| 检查 | 规则 |
|---|---|
| 数字溯源 | 报告中每个数字必须出现在事实数据包（含年报证据）中 |
| 页码核验 | 每个"20XX年报第N页"必须通过 RAG 引用核验；"第22页、第15页"自动继承年份 |
| 评级/区间 | 必须与规则计算结果一致 |
| 结构 | 七个章节齐全 |
| 待验证事项 | 统计"待年报验证"数量 |

已排除非数据数字：小节编号、列表序号、年份、日期、排名（第2/5）、页码、股票代码（项目一的经验）。

## 局限（如实说明）
- 只比较数值，不理解上下文：数据包里碰巧有相同数值时，模型自行计算的数字可能被误判为"可溯源"（v2 的 +0.09）。
- **只能发现"数字错"，发现不了"逻辑错"**：v1 数字溯源率 100%，人工审阅仍发现 4 处比较错误。这正是需要审稿 Agent 的原因。
