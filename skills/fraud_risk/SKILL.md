# 技能 4：风险识别（从项目一复用并升级）

## 输入
`data/raw/{code}_资产负债表/利润表/现金流量表/折旧摊销.csv`

## 输出
- `data/processed/{code}_fraud_risk.csv`：每家公司逐年指标、红旗、主要驱动
- `data/processed/fraud_risk.json`：目标公司摘要（供报告撰写技能读取）

## 运行
```
python skills/fraud_risk/ratios.py
```

## 方法
- **5变量 M-Score**（阈值 -2.22）与 A 股红旗规则：与项目一完全相同，体现技能复用。
- **8变量 M-Score**（阈值 -1.78）：项目一缺折旧数据无法计算，本项目补齐后升级。
- **驱动归因**：贡献 = 系数 ×（指数 − 1），TATA 与 0 比较，列出贡献最大的变量。

## 案例
云南白药 2022 年 M-Score 报警，归因显示 AQI=3.79 贡献 +1.66；年报（RAG）证实原因是约113亿元战略入股上海医药（权益法核算），属于模型误报。
