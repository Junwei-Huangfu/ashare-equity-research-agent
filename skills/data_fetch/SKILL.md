# 技能 1：数据采集

## 何时使用
任何分析开始前。下游所有技能都只读取本技能保存在 `data/raw/` 的文件，不直接访问网络。

## 输入
- `COMPANIES`（本文件内）：目标公司放在第一位，其余为可比公司。**这是全项目唯一需要修改公司名单的地方。**

## 输出（`data/raw/`）
| 文件 | 来源 | 用途 |
|---|---|---|
| `{code}_资产负债表/利润表/现金流量表.csv` | 新浪财经 | 财务分析、估值、风险识别 |
| `{code}_折旧摊销.csv` | 东方财富现金流量表补充资料 | DCF、EV/EBITDA、8变量M-Score |
| `{code}_估值行情.csv` | 东方财富 | 股价、总股本、市值、PE、PB |
| `{code}_日线后复权.csv`、`指数_沪深300.csv` | 新浪 | Beta 回归 |
| `无风险利率_中国10年国债.csv` | 中美国债收益率 | WACC |

## 运行
```
python skills/data_fetch/data_fetch.py              # 有缓存则跳过
python skills/data_fetch/data_fetch.py --refresh    # 强制重新下载
```

## 关键设计
- **先探测、再选型**：在澳洲测试了 5 个接口，东方财富个股信息/日线接口海外不可用，最终选用可稳定访问的接口。
- **折旧摊销交叉验证**：新浪无折旧数据；东方财富与同花顺单项口径不同（使用权资产折旧的归类），加总后一致（2025年约4.14亿元），选用精度更高的东方财富。
- **本地缓存**：下载一次后重复运行不再请求数据源。
